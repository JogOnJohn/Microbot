# Microbot Utility Reference Map (MCP-Style Index)

This document maps core game data and utility classes used throughout the Microbot project. Use it as the first stop when implementing, automating, or debugging features.

## Game Data Reference

**Authoritative sources and lookup instructions for core game data used by Microbot utilities and plugins.**

### Item IDs
- **Source:** [`runelite-api/src/main/java/net/runelite/api/ItemID.java`](runelite-api/src/main/java/net/runelite/api/ItemID.java)
- **Description:** Autogenerated static integer fields for every item in the game. Example: `ItemID.EXCALIBUR = 35`. Most items follow the `ITEM_NAME` pattern in the item database.
- **Usage Pattern:**
  - In Java: `ItemID.EXCALIBUR` or `ItemID.BRONZE_ARROWTIPS`
  - In AI/Markdown: look up by name, then use the constant or integer value.
- **Sample Table:**

| Name    | ID |
|---------|----|
| TOOLKIT | 1  |
| CANNONBALL | 2 |
| ... | ... |

### Monster/NPC IDs & Stats
- **Source:** [`util/npc/Rs2NpcManager.java`](util/npc/Rs2NpcManager.java) (loads data from `npc/monsters_complete.json` and related JSON files)
- **Description:** Provides all monster/NPC IDs, names, stats, and spawn locations. Used by AIO Fighter and other combat plugins.
- **Usage Pattern:**
  - Get stats: `Rs2NpcManager.getStats(npcId)`
  - Get locations: `Rs2NpcManager.getNpcLocations(npcName)`
  - Closest spawn: `Rs2NpcManager.getClosestLocation(npcName)`
- **Sample Table:**

| Name | ID | HP | Attack | Defence | Locations (WorldPoint) |
|------|----|----|--------|---------|------------------------|
| Goblin | 100 | 5 | 1 | 1 | (3245, 3248, 0), ... |
| Cow | 81 | 8 | 1 | 1 | (3256, 3266, 0), ... |
| ... | ... | ... | ... | ... | ... |

## Rs2Inventory (`util/inventory/Rs2Inventory.java`)
**Purpose:** Manage inventory: item checks, interaction, slot access, using/destroying items, and inventory state.

**Key Methods:**
- `ItemContainer inventory()` — Returns inventory container.
- `boolean hasUnNotedItem(String name[, boolean exact])` — Check for unnoted item.
- `int getFirstEmptySlot()` — First empty slot index.
- `void waitForInventoryChanges(Runnable action, int time, int timeout)` — Wait for inventory to change after an action.

**Related:** Rs2Bank, Rs2Widget, Rs2GameObject

**Usage Notes:**
- Supports exact/partial name matching.
- Handles inventory widgets for bank/shop/GE contexts.

---

## Rs2Dialogue (`util/dialogues/Rs2Dialogue.java`)
**Purpose:** Automate all in-game dialogues: NPC, player, options, cutscenes, and combinations.

**Key Methods:**
- `boolean isInDialogue()` — True if any dialogue is active.
- `void clickContinue()` — Simulate space key for "Click here to continue".
- `void waitForCutScene(int time, int timeout)` — Wait for cutscene.

**Related:** Rs2Widget, Rs2Keyboard

**Usage Notes:**
- Relies on widget checks, not ChatMessage events.
- Supports exact/partial text matching.
- Handles conditional UI delays.

---

## Rs2GameObject (`util/gameobject/Rs2GameObject.java`)
**Purpose:** Find and interact with world objects (doors, chests, altars, etc.), including decorative and wall objects.

**Key Methods:**
- `boolean interact(GameObject | TileObject | int id | String name, [String action], [boolean exact], [int distance])` — Interact with objects by type/ID/name/action.
- `boolean exists(int id)` — Check if object exists.
- `boolean canReach(WorldPoint target, ... )` — Check reachability.
- `List<TileObject> getAll([Predicate, distance, anchor])` — Find objects by filter.

**Related:** Rs2Player, Rs2Tile, Rs2Inventory

**Usage Notes:**
- Flexible search by ID, name, anchor, or predicate.
- Supports local/world coordinates and reachability checks.

---

## Rs2Player (`util/player/Rs2Player.java`)
**Purpose:** Access player state, skills, buffs, combat, run energy, and nearby players.

**Key Methods:**
- `boolean hasAntiFireActive()` — Check anti-fire buff.
- `boolean hasStaminaBuffActive()` — Check stamina buff.
- `int getCombatLevel()` — Get combat level.
- `Stream<Player> getPlayers(Predicate, boolean includeLocal)` — Stream nearby players.
- `boolean logout()` — Log out player.
- `Player getPlayer(String name[, boolean exact])` — Find player by name.

**Related:** Rs2Inventory, Rs2GameObject, Rs2Bank

**Usage Notes:**
- Many methods run on the client thread for safety.
- Deprecated methods are marked; use newer overloads.

---

## Rs2Walker (`util/walker/Rs2Walker.java`)
**Purpose:** Handle all pathfinding, walking, and teleportation logic.

**Key Methods:**
- `boolean walkTo(WorldPoint | int x, int y, int plane[, int distance])` — Walk to world point.
- `WalkerState walkWithState(WorldPoint target, int distance)` — Walk with feedback state.
- `boolean walkNextTo(GameObject target)` — Walk next to object.
- `boolean processWalk(WorldPoint target, int distance)` — Core walk logic (doors, teleports, etc.).
- `void recalculatePath()` — Force path recalculation.

**Related:** Rs2Player, Rs2GameObject, Rs2Bank

**Usage Notes:**
- Uses shortest-path plugin for advanced pathfinding.
- Supports walking and teleport-based movement.
